# teach-me — Fase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir la fase 1 de la skill `teach-me`: la base (investigar a partir de una URL, guardar
todo en Markdown por librería, buscar en local) y el modo **«Estudiar cómo se usa»** completo
(temario, lecciones, exámenes corregidos, repaso, avance, retomar y actualizar), con workers de
modelo bajo para las consultas, el respaldo de las citas y la corrección.

**Architecture:** Igual que `explain-changes`. `scripts/teach_me.py` solo despacha subcomandos; la
lógica vive en `scripts/teach_me_lib/`. El script es lo único que descarga y escribe, y cada
subcomando imprime un objeto JSON. En disco todo es Markdown con una cabecera entre `---` que el
script lee y escribe. La IA investiga leyendo lo descargado, manda el contenido por stdin y enseña
siguiendo `SKILL.md` y `references/`.

**Tech Stack:** Python 3.9+ (solo biblioteca estándar: `argparse`, `json`, `urllib`, `tarfile`,
`html.parser`, `hashlib`, `math`), `unittest`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-28-teach-me-design.md` (versión 4, aprobada). Este plan
cubre solo la **fase 1** de su §13. Quien ejecute el plan lee los dos.

## Global Constraints

- Python 3.9 o superior, **solo biblioteca estándar**. Todo módulo empieza con `from __future__ import annotations`.
- Rutas: `skills/teach-me/` (lo que se instala), `tests/teach-me/`, `docs/teach-me.md`.
- Cada subcomando imprime **un único objeto JSON** en UTF-8. Salida 0 = bien; 2 = bloqueo esperado `{"ok": false, "error": {"code", "message"}}`; 1 = error interno con `code: "internal_error"`. Los errores de argparse son `bad_input` (salida 2).
- Raíz de datos: `$TEACH_ME_HOME` si existe; si no, `~/.teach-me`. El script es el único que escribe ahí. Toda escritura es atómica (archivo temporal en la misma carpeta y `os.replace`). **No hay bases de datos ni JSON en disco**: todo son archivos `.md`, salvo el código descargado, que se guarda tal cual.
- Los nombres de archivos y carpetas siguen el idioma del expediente (tabla de spec §5.2), que se fija al crearlo.
- `SKILL.md` va en inglés. La skill habla con la persona en el idioma de la conversación.
- Frontmatter de `SKILL.md`: `disable-model-invocation: true`. Además, `agents/openai.yaml` con `allow_implicit_invocation: false`.
- Red: solo `http`/`https`. `User-Agent: teach-me-skill` y timeout de 30 s. `GITHUB_TOKEN` se lee del entorno solo para `api.github.com` y `codeload.github.com`; **nunca** se escribe en disco ni sale en el JSON.
- Las pruebas no usan red real: servidor HTTP local y variables de entorno que sustituyen las URLs base.
- Nunca se ejecuta código descargado. El contenido descargado es dato, nunca instrucción.
- Umbrales de la spec: **más del 50 % = bien; 50 % o menos = mal**. Un examen se aprueba si el promedio **pasa del 50 %**. De **5 a 8** preguntas por examen. Como máximo **una** `read_yourself`. El repaso tiene de **2 a 3** preguntas y no cambia las notas. Una pregunta está repetida si su Jaccard de palabras es **≥ 0,8**.
- Modos (spec §1): `overview` (1), `overview-internals` (2), `use` (3) y `use-internals` (4). En la fase 1 solo existe `use`; los otros tres responden con el bloqueo `mode_not_available`.
- Sin código público (spec §8.5): la investigación sigue solo con la web y la documentación, y no se deduce nada de cómo está construida. En la fase 1 solo se descarga código de GitHub.
- **Git:** trabajar en una rama propia, nunca en `main`. Hacer un commit al final de cada tarea, **sin push** y **sin líneas de atribución a una IA** (`Co-Authored-By`, «Generated with…»). La persona sube la rama e integra.
- Subagentes, si se usan: **de uno en uno**, nunca en paralelo.

## Review Focus

1. **URL escrita de otra forma** (`https://www.AI-SDK.dev/docs/#x`, con barra final o con `?utm_source=`): encuentra el mismo expediente que `https://ai-sdk.dev/docs`. La prueba está en la Task 2.
2. **Tarball malicioso** (entrada `../evil`, ruta absoluta, symlink que sale): nada se escribe fuera de la carpeta del código, y la entrada se apunta en la cobertura. La prueba está en la Task 5.
3. **Una variante `.md` que devuelve HTML** (SPA que responde 200 con `text/html`): se trata como si no existiera `.md`, y la página HTML se convierte. La prueba está en la Task 4.
4. **Nota justo en el límite:** 50 en una abierta es mal, y un promedio de 50 no aprueba. La prueba está en la Task 10.
5. **Investigación cortada:** un segundo `fetch-docs` no vuelve a descargar lo ya guardado, y `lookup` devuelve `status: investigating` para retomar. Las pruebas están en las Tasks 2 y 4.

**Cómo se reconoce cada archivo sin depender del idioma:** toda cabecera escrita por el script
lleva `teach_me: "<tipo>"`, con uno de `profile`, `syllabus`, `topic`, `exam`, `progress`, `page`,
`meta`, `config` o `index`. La ficha de un expediente es el `.md` de su carpeta raíz con
`teach_me: "profile"`.

### Task 2: URLs, fichas, `lookup`, `list`, `init` y `add-root`

**Files:**
- Create: `teach_me_lib/urls.py`, `teach_me_lib/dossier.py`
- Modify: `scripts/teach_me.py`

**Interfaces:**
- Produces:
  - `urls.normalize(url: str) -> str`: si no es `http`/`https` con dominio → `bad_input` con `not_a_url`. Dominio en minúsculas, sin `www.`, sin puerto por defecto, sin query, sin fragmento y sin barra final. El resultado no lleva esquema (`ai-sdk.dev/docs`).
  - `urls.root_for(url: str) -> str`: GitHub → `github.com/<owner>/<repo>` (sin `.git`); npm → `npmjs.com/package/<name>` (incluido `@scope/name`); PyPI → `pypi.org/project/<name>`; dominios compartidos (`github.io`, `vercel.app`, `readthedocs.io`, `netlify.app`, `pages.dev`, `gitlab.io`) → dominio + primer segmento; cualquier otro → la URL normalizada.
  - `urls.matches(url_norm: str, root: str) -> bool`: prefijo que respeta los límites de segmento.
  - Cabecera de la ficha: `teach_me: "profile"`, `id`, `lang`, `names` (el diccionario resuelto), `mode: "use"`, `parts_done: []` (de `overview`, `use` e `internals`), `public_code: null` (`true` o `false` cuando se sabe), `status: "investigating"|"ready"`, `phases: {}`, `roots: [..]`, `input_url`, `name`, `one_liner`, `links: {}`, `license: {}`, `version: {}` y `coverage: {"read": [], "skipped": [], "not_downloaded": []}`.
  - `dossier.find_all() -> list[dict]`: recorre `<home>/*/`, abre los `.md` del primer nivel y devuelve las cabeceras con `teach_me == "profile"`.
  - `dossier.lookup(url: str) -> dict` → `{"ok": true, "match": "existing"|"new"|"ambiguous", "normalized", "id"?, "status"?, "mode"?, "candidates"?: [{"id","name","roots"}]}`, con el algoritmo de spec §4: gana la raíz más larga; un empate entre expedientes, o el mismo dominio sin prefijo, es `ambiguous`.
  - `dossier.list_all() -> list[dict]` con `{"id","name","roots","mode","version","status"}`.
  - `dossier.init(url: str, lang: str, mode: str, custom_names: dict | None) -> dict`: un `mode` distinto de `use` → `mode_not_available`. Es idempotente: si es `existing`, devuelve ese expediente; si es `ambiguous` → `ambiguous_url`. El id sale de la raíz en slug y, si choca, lleva `-2`, `-3`… Crea las carpetas con los nombres resueltos y la ficha.
  - `dossier.add_root(dossier_id: str, url: str) -> dict`
  - `dossier.load(dossier_id) -> tuple[dict, str]` y `dossier.save(dossier_id, meta: dict) -> None`. `save` regenera el cuerpo legible de la ficha y el `README.md` raíz (`teach_me: "index"`; una tabla de librería, URLs, versión, modo y estado, en el idioma de cada expediente).
  - CLI: `lookup <url>`, `list`, `init <url> --lang <code> --mode use [--names-stdin]` y `add-root <id> <url>`.

### Task 3: Red, metadatos (`fetch-meta`) y `update-profile`

**Files:**
- Create: `teach_me_lib/net.py`, `teach_me_lib/meta.py`

**Interfaces:**
- Produces:
  - `net.get(url: str, max_bytes: int) -> net.Response` con `status`, `content_type`, `body: bytes` y `final_url`. Errores: `fetch_failed` (red o 5xx), `too_large` y `github_rate_limited` (403 o 429 de GitHub, con un mensaje que menciona `GITHUB_TOKEN`). Un 404 no es error: devuelve `status=404`.
  - `net.base(name)`: para `npm`, `pypi`, `github_api` y `codeload`, se sustituyen con `TEACH_ME_NPM_REGISTRY`, `TEACH_ME_PYPI_BASE`, `TEACH_ME_GITHUB_API` y `TEACH_ME_CODELOAD`. Por defecto: `https://registry.npmjs.org`, `https://pypi.org/pypi`, `https://api.github.com` y `https://codeload.github.com`.
  - `meta.fetch_meta(dossier_id, npm: str | None, pypi: str | None, repo: str | None) -> dict`. Guarda cada respuesta cruda como `<meta_dir>/<origen>.md` (`teach_me: "meta"`, con `url` y `fetched_at` en la cabecera y el JSON en un bloque de código). Devuelve `{"ok","package": {"registry","name","latest","license"}?, "repo": {"full_name","default_branch","size_kb","license_spdx","head_sha","pushed_at"}?, "license": {"registry","repo","match"}, "tag", "notices"}`. Escribe en la ficha `version` (`{"kind": "package"|"snapshot", "value", "tag", "sha", "label", "docs_fingerprint", "other_packages"}`) y marca la fase `meta`. Límite de 5 MB por respuesta.
  - `meta.find_tag(repo, package, version) -> str | None`: prueba, en este orden, `<package>@<version>`, `v<version>`, `<version>` y `<package>-v<version>` contra `GET /repos/{repo}/git/ref/tags/<tag>`. Si ninguno existe → aviso `tag_not_found` y `label` = el sha.
  - `version.label`: el tag o el sha con `/` y `@` cambiados por `_` (`ai_7.0.155`).
  - `dossier.update_profile(dossier_id, patch: dict) -> dict`. Claves permitidas: `name`, `one_liner`, `links` (`web`, `docs`, `repo`, `package: {registry, name}`), `public_code` (booleano), `coverage` (se añade a las listas) y `phase_done` (`meta`, `docs_discover`, `docs`, `code` o `syllabus`). Con `public_code: false`, la fase `code` cuenta como terminada sin descargar nada, y la cobertura apunta `no_public_code`. Cualquier otra → `bad_input`. Cada enlace se añade como raíz con `root_for`.
  - CLI: `fetch-meta <id> [--npm NAME | --pypi NAME] [--repo OWNER/NAME]` y `update-profile <id>` (JSON por stdin).
  - `helpers.FixtureServer(routes: dict[str, tuple[int, str, bytes]])`: un `ThreadingHTTPServer` en `127.0.0.1:0` con `.url(path)`, `.env()` (las cuatro URLs base apuntando a sí mismo) y `.requests` (la lista de rutas pedidas, con sus cabeceras).

### Task 4: Documentación (`discover-docs` y `fetch-docs`)

**Files:**
- Create: `teach_me_lib/html2md.py`, `teach_me_lib/docs.py`
- Modify: `scripts/teach_me.py`
- Test: `tests/teach-me/test_html2md.py`, `tests/teach-me/test_docs.py`

**Interfaces:**
- Produces:
  - `html2md.convert(html: str) -> str`: `html.parser` sin `script`, `style`, `nav`, `footer` ni `header`; `h1`–`h6` → `#`; `p` → párrafos; `pre`/`code` → bloques con tres comillas invertidas; `a` → `[texto](href)`; `li` → `- `; `table` → filas separadas por `|`.
  - `docs.discover(dossier_id, docs_url) -> dict`: busca en este orden `<docs_url>/llms.txt`, `<origen>/llms.txt`, `<origen>/sitemap.xml` (siguiendo los `sitemapindex`) y, por último, los `<a href>` de `docs_url`. Se queda con las URLs bajo el prefijo de `docs_url`, sin duplicados, hasta **2000** (el resto va a `coverage.not_downloaded` con `page_limit`). Guarda la lista en `<docs_dir>/_pages.md` (cabecera `teach_me: "index"` con `pages: [{"url","state","reason"}]`) y escribe `version.docs_fingerprint` (sha256 del índice usado). Devuelve `{"ok","method":"llms_txt"|"sitemap"|"links","page_count","fingerprint"}`.
  - `docs.fetch(dossier_id, url: str | None) -> dict`: sin `url`, descarga las páginas pendientes de `_pages.md`; con `url`, solo esa (y la añade a la lista). Para cada página prueba primero `<url>.md`, que se acepta solo si responde 200 con un `content-type` distinto de `text/html` y un cuerpo que no empiece por `<!doctype` ni por `<html`. Si no, descarga el HTML y lo convierte con `html2md`. Límite de **2 MB** por página. Guarda `<docs_dir>/<ruta normalizada con / → __>.md` con la cabecera `teach_me: "page"`, `url`, `fetched_at` y `origin: "md"|"html"`. Una página en estado `ok` no se vuelve a descargar. Devuelve `{"ok","downloaded","already","failed":[{"url","reason"}]}`.
  - `docs.page_path(dossier_id, url) -> Path | None`
  - CLI: `discover-docs <id> <docs_url>` y `fetch-docs <id> [--url URL]`.
